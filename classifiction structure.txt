Campus Adaptive Reuse Framework
Knowledge Precedent Taxonomy

This project uses a six-layer taxonomy. Layer 6 was added for adaptive transformation logic, including adaptation model, spatial behavior, organizational mechanism, and transformation drivers.

1. Architectural Layer
  1-1 Structural System
    - structural_regularity
    - large_span_space
    - modular_degree
    - floor_height_condition

  1-2 Spatial Organization
    - plan_composition
    - circulation_system
    - atrium_courtyard_corridor
    - spatial_openness

  1-3 Spatial Character
    - spatial_scale
    - publicness
    - rituality
    - industrial_historical_atmosphere

2. Urban Context Layer
  2-1 Historical Context
    - industrial_heritage
    - military_heritage
    - campus_history
    - local_memory

  2-2 Urban Relationship
    - urban_interface
    - campus_openness
    - community_connection
    - public_accessibility

  2-3 Environmental Condition
    - natural_daylighting
    - natural_ventilation
    - microclimate
    - green_environment

3. Temporal Transformation Layer
  3-1 Historical Evolution
    - building_year
    - renovation_year
    - historical_layering
    - spatial_evolution

  3-2 Functional Transformation
    - teaching_space

    - mixed_use

  3-3 Adaptive Capacity

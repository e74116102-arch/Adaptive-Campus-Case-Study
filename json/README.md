# JSON Output

The JSON files in this folder are generated by:

```powershell
python scripts\extract_campus_precedents.py
```

## Files

| File / Folder | Purpose |
|---|---|
| `campus_knowledge_precedents.json` | Full database. Contains metadata, the six-layer taxonomy, and all 20 complete cases. |
| `case_overview.json` | Compact case overview with browsing indexes. |
| `taxonomy.json` | Six-layer Knowledge Precedent taxonomy. |
| `cases/` | One complete JSON file per case. |

The repository root also contains:

```text
campus_knowledge_precedents_MyGPT_upload.json
```

That file is an exact upload copy of `json/campus_knowledge_precedents.json` for My GPT.

## Six-Layer Taxonomy

The taxonomy contains:

1. `architectural_layer`
2. `urban_context_layer`
3. `temporal_transformation_layer`
4. `functional_layer`
5. `typology_layer`
6. `adaptive_transformation_layer`

The sixth layer includes:

- `adaptation_model`
- `behavior`
- `organizational_driver`
- `transformation_driver`

## `case_overview.json`

Each overview case includes:

- case number
- case id
- case name
- original function
- current function
- region / country
- year
- location
- key spatial features
- keywords
- case image references
- adaptive transformation analysis
- typology tags
- six-layer taxonomy tags
- spatial vocabulary
- semantic relations

The overview also includes these indexes:

- `by_region_country`
- `by_typology`
- `by_keyword`
- `by_behavior`
- `by_organizational_driver`
- `by_transformation_driver`

## Complete Case Records

Each case in `cases/` and in `campus_knowledge_precedents.json` includes:

- `raw_fields`
- `case_images`
- `adaptive_transformation_analysis`
- `knowledge_precedent`
- `precedent_dna`
- `notes`

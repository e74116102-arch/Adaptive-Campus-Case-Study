This document explains the repository structure and the role of each file.

```text
Adaptive-Campus-Case-Study/
+-- README.md
+-- GPT_Site_Context_Analysis_Prompt.md
+-- campus_cases.xlsx
+-- campus_knowledge_precedents_MyGPT_upload.json
+-- classifiction structure.txt
+-- LICENSE
+-- docs/
|   +-- FOLDER_STRUCTURE.md
+-- json/
|   +-- campus_knowledge_precedents.json
|   +-- case_overview.json
|   +-- taxonomy.json
|   +-- README.md
|   +-- cases/
|       +-- case_01_lehigh_university_packer_hall.json
|       +-- case_02_nottingham_trent_university.json
|       +-- ...
|       +-- case_20_aalto_university_harald_herlin_learning_centre.json
+-- scripts/
    +-- extract_campus_precedents.py
    +-- README.md
```

## Root Files

### `README.md`

Repository overview, six-layer taxonomy summary, My GPT upload guidance, and regeneration command.

### `GPT_Site_Context_Analysis_Prompt.md`

Custom GPT Instructions prompt. It tells My GPT how to use the case database, classify sites with the six-layer taxonomy, retrieve precedents, and produce machine-readable JSON.

### `campus_knowledge_precedents_MyGPT_upload.json`

Recommended single file for My GPT knowledge upload. It is generated by the extraction script and should match `json/campus_knowledge_precedents.json`.

### `campus_cases.xlsx`

Source spreadsheet for the 20 case records.

### `classifiction structure.txt`

Human-readable taxonomy outline. The filename keeps the original spelling `classifiction` to avoid breaking existing references.

## `json/`

Generated structured JSON data.

### `json/campus_knowledge_precedents.json`

Full database containing:

- `metadata`
- `taxonomy`
- `cases`

Each case includes source fields, image references, adaptive transformation analysis, six-layer taxonomy classification, and Precedent DNA.

### `json/case_overview.json`

Compact browsing and filtering file. It includes indexes by:

- region / country
- typology
- keyword
- behavior
- organizational driver
- transformation driver

### `json/taxonomy.json`

Six-layer taxonomy:

1. `architectural_layer`
2. `urban_context_layer`
3. `temporal_transformation_layer`
4. `functional_layer`
5. `typology_layer`
6. `adaptive_transformation_layer`

### `json/cases/`

One full JSON file per case.

## `scripts/`

### `scripts/extract_campus_precedents.py`

Reads `campus_cases.xlsx` and regenerates:

- `json/taxonomy.json`
- `json/campus_knowledge_precedents.json`
- `json/case_overview.json`
- `json/cases/*.json`
- `campus_knowledge_precedents_MyGPT_upload.json`

Run:

```powershell
python scripts\extract_campus_precedents.py
```

## My GPT Workflow

1. Upload `campus_knowledge_precedents_MyGPT_upload.json` to My GPT knowledge.
2. Use `GPT_Site_Context_Analysis_Prompt.md` as My GPT Instructions.
3. Ask My GPT to retrieve precedents, classify a site, or translate case logic into design guidance.
